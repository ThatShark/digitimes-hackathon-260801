# 智慧投資 LIVE

> 第一個認識你、分析你、然後幫你下單的 AI 投資助理。

---

## 專案簡介

智慧投資 LIVE 是一個以 YouTube 直播風格為介面的 AI 加密貨幣投資工具。
每個幣種對應一個「直播頻道」，AI 根據你的個人交易習慣分析投資人格，並提供個人化的市場分析與下單建議。

---

## 核心功能

- 🦁 **投資人人格分析**：根據歷史交易紀錄，分析你的投資風格
- 📺 **直播風格 UI**：每個幣種對應一個直播頻道，K 線圖即時呈現
- 🤖 **AI 對話下單**：用自然語言與 AI 討論，確認後直接執行交易
- 📊 **個人化市場分析**：結合市場情緒與你的歷史勝率給出建議

---

## 技術架構

- **前端**：React + Vite + lightweight-charts
- **後端**：AWS Lambda + API Gateway
- **AI**：AWS Bedrock（Claude）
- **儲存**：AWS S3
- **交易**：MAX Exchange API + MAX Skill
